# Carpeta de imágenes / Images folder

Aquí van TODOS los fondos del sitio. Para cambiar una imagen, simplemente
**reemplaza el archivo por el tuyo usando EXACTAMENTE el mismo nombre**.
No hay que tocar el HTML ni el CSS: el sitio ya apunta a estos nombres.

Ahora mismo son **placeholders** (fondos navy generados). Cámbialos por
fotos reales cuando quieras.

## Fondos de sección (recomendado: 1920×1000 px aprox., horizontal, JPG)

| Archivo          | Sección  | Qué foto poner |
|------------------|----------|----------------|
| `home.jpg`       | Home     | La que ya te gustaba: rascacielos de vidrio / skyline moderno mirando hacia arriba. |
| `about.jpg`      | About    | Planos / manos sobre planos arquitectónicos. **Limpia, sin manchones oscuros a la derecha.** |
| `services.jpg`   | Services | Ingeniería real: planos técnicos, detalle estructural, pantalla de BIM/Revit, obra en detalle. |
| `sectors.jpg`    | Sectors  | Algo **distinto al Home**: aérea urbana variada, distintos tipos de edificio, no otro skyline igual. |
| `projects.jpg`   | Projects | Algo **impactante**: obra con grúas, arquitectura potente, no genérico. |
| `global.jpg`     | Global   | **Panorámica hermosa de Canadá** (skyline de Toronto / Ontario, o paisaje canadiense icónico). |
| `contact.jpg`    | Contact  | Algo **cálido y humano**: reunión cliente-profesional, apretón de manos, equipo en oficina. |

## De dónde sacar fotos gratis (uso comercial permitido)

- Unsplash: https://unsplash.com  (buscar: "modern architecture", "engineering blueprint",
  "construction site", "toronto skyline", "business meeting")
- Pexels: https://pexels.com
- Pixabay: https://pixabay.com

## Consejos
- Prefiere fotos **oscuras o con zonas oscuras a la izquierda** (ahí va el texto blanco).
- Evita fotos con una mancha muy oscura o muy clara justo donde va el título.
- Mantén el nombre de archivo. Si cambias el nombre, se rompe el fondo.
- Después de subir a GitHub, refresca con **Ctrl + Shift + R**.
